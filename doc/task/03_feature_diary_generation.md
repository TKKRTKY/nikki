# 機能タスク: 日記生成機能

## 概要

LLMとの会話内容から日記本文を生成し、保存する機能を実装する。

## 前提条件

- LLM設定機能が完了していること
- チャット機能が完了していること

## 作業内容

### 1. データ型定義

- [ ] 日記エントリ（DiaryEntry）の型定義

### 2. 日記生成ロジック

- [ ] `lib/diary.ts` に日記生成機能
- [ ] 会話ログを元にした日記生成プロンプト作成
- [ ] LLM APIを使用した日記本文生成
- [ ] 生成された日記の後処理（フォーマット調整等）

### 3. 日記データ管理

- [ ] IndexedDBに日記エントリ保存機能
- [ ] 今日の日記取得・更新機能
- [ ] 1日1エントリの制約実装

### 4. 日記生成UI

- [ ] 「日記を生成する」ボタン
- [ ] 生成中のローディング表示
- [ ] 生成された日記本文の表示エリア
- [ ] 日記の編集機能（任意）
- [ ] 日記保存確認

### 5. メインページ統合

- [ ] チャット機能と並行して日記表示エリア配置
- [ ] 既存の今日の日記があれば表示
- [ ] 生成ボタンの状態管理

## 動作確認項目

- [ ] チャット後に日記生成ボタンから日記が作成される
- [ ] 生成された日記が保存される
- [ ] 既存の日記がある場合は上書き確認
- [ ] ページリロード後も日記が表示される
- [ ] 日記生成失敗時の適切なエラー表示

## 完了条件

ユーザーがLLMとの会話から日記を生成し、保存・表示できる状態が動作する。
