# 機能タスク: チャット機能

## 概要
LLMとリアルタイムでチャット形式の会話ができる機能を実装する。

## 前提条件
- LLM設定機能が完了していること

## 作業内容

### 1. データ型定義
- [ ] 会話ログ（ConversationLog）の型定義
- [ ] API呼び出しレスポンスの型定義

### 2. LLM API呼び出し
- [ ] `lib/llm.ts` にOpenAI互換API呼び出し関数
- [ ] 設定されたBase URL、Model、API Keyを使用
- [ ] エラーハンドリング（APIキー無効、ネットワークエラー等）

### 3. 会話ログ管理
- [ ] IndexedDBに会話ログ保存機能
- [ ] 今日の日付に紐づく会話ログの取得
- [ ] 会話履歴の表示

### 4. チャットUI
- [ ] チャット画面コンポーネント作成
- [ ] メッセージ入力欄（音声入力ツール対応）
- [ ] 送信ボタン
- [ ] 会話履歴表示（ユーザー/AI区別）
- [ ] 送信中のローディング表示

### 5. メインページ統合
- [ ] LLM設定完了時にチャット機能を表示
- [ ] 今日の会話ログを読み込み表示

## 動作確認項目
- [ ] テキストを入力してLLMから応答が返る
- [ ] 会話履歴がリアルタイムで表示される
- [ ] 会話ログがIndexedDBに保存される
- [ ] ページリロード後も会話履歴が保持される
- [ ] API呼び出しエラー時に適切なエラー表示

## 完了条件
ユーザーがLLMとチャット形式で会話でき、会話履歴が保存・表示される状態が動作する。
