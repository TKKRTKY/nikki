# 機能タスク: LLM設定機能

## 概要
ユーザーがLLM API（Base URL、Model、API Key）を設定・保存できる機能を実装する。

## 作業内容

### 1. データ型定義
- [ ] `types/index.ts` にLLMSettings型を定義
- [ ] IndexedDB用のデータベース設計

### 2. IndexedDB操作
- [ ] `lib/db.ts` にIndexedDB操作関数を実装
- [ ] LLM設定の保存・取得機能

### 3. UI実装
- [ ] LLM設定フォームコンポーネント作成
- [ ] Base URL、Model、API Key入力フィールド
- [ ] 保存・クリアボタン

### 4. メインページ統合
- [ ] `/app/page.tsx` に設定フォーム統合
- [ ] 設定未完了時の表示制御
- [ ] 設定完了時の折りたたみ表示

## 動作確認項目
- [ ] フォームに入力した内容が保存される
- [ ] ページリロード後も設定が保持されている

## 完了条件
